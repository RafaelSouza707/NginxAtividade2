# NginxAtividade2

Repositório destinado à Atividade 2 envolvendo implantação de uma aplicação **ReactJS** servida pelo **Nginx**, além da execução de testes de carga utilizando **Apache Bench (ab)**.

---

## Conteúdo do Repositório

Este projeto contém dois tutoriais em Markdown:

- [redirecionamento_react.md](./redirecionamento_react.md)  
  Tutorial sobre atualização da configuração do Nginx para suportar corretamente rotas internas de uma aplicação ReactJS (SPA).

- [apache_bench.md](./apache_bench.md)
  Tutorial sobre instalação, configuração e execução de testes de carga na Home de uma aplicação ReactJS utilizando Apache Bench.
